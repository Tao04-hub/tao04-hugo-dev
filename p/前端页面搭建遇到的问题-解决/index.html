前端页面搭建遇到的问题+解决

2026年3月4日星期三

常见名词：

切包：网络传输中，把一个完整数据包拆分成多个小数据包发送，接收方再还原，解决 “粘包” 问题（数据粘在一起难区分）。

1.浏览器缓存问题

问题：Hugo 已经检测到 custom.css 的变化并重新构建了网站，但页面样式没有变化。

原因：浏览器为了加载速度，会缓存静态资源（如 CSS），即使服务器更新了文件，浏览器也可能继续使用旧版本。

请求头和响应头：

请求头：客户端->服务端，说明附加信息；

响应头：服务端->客户端，返回时的说明信息。

不同的命令对应不同的缓存响应方式。->要求服务器进行精准的网络字段配置。

1.catchcontrol:设置时间a，在时间a内重复访问服务器，不会向服务器重新发送请求，而是直接返回时间a前的服务器。时间a结束之后，才会重新请求真实的服务器数据。

2.expires:设置过期时间expires，在过期时间内重复请求，则无需再次访问服务器，直接从缓存里拿数据。

3.etag（需搭配if-none-match使用）（又称为协商缓存）:

首次访问服务器时，服务端产生etag，业务端要在下次请求时，在请求头加上if-none-match：etag;

再次访问服务器时，服务端判断etag?=if-none-match，

if==，服务端直接返回304，业务端直接返回之前本地缓存的数据；

if!=，业务端访问服务器拿数据。

4.last-modified（最新修改时间）（需搭配if-modified-since使用）:

首次访问服务器时，服务端产生last-modified，

业务端缓存last-modified和数据，并在下一次请求时在请求头带上if-modified-since；

再次访问服务器时，判断if-modified-since ?>= last-modified，

if true,数据未变，返回304，直接访问缓存数据。

理解：在最新修改时间后，查看是否又修改过。

2.hugo博客搭建

（1）在dev/hugo.toml下写基本语句。

（2）先清除public文件夹下的所有内容，

cd定位到dev目录下，用bash打开，再：

生成静态文件 hugo

启动本地服务器 hugo server

/启动本地服务器并加载所有子目录hugo server ==-==D 或 hugo server ==–==builDrafts

（3）将主题配置里的layouts文件夹（内含主题提供的一些简单页面）替换dev文件夹下的layouts文件夹。

3.Hugo 无法识别同名嵌套的主题结构

在github上下载的主题有时会嵌套了两层同名文件夹，Hugo 无法识别这种嵌套结构，需要手动剥去其中一层文件，防止嵌套文件夹无法被识别。并且版本号要删去，防止无法识别。

4.变换主题时要修改全局配置（hugo.toml）

根目录dev下的hugo.toml为Hugo 启动时优先读取的全局核心配置文件，控制整个项目的主题、基础配置。

主题作者提供的主题配置，展示该主题支持的配置项（仅参考），在该文件里的所有修改均无法生效到页面上。

具体修改步骤：

（1）将主题文件夹放在themes文件夹中，删除嵌套，重命名主题文件夹（删去版本号等后缀）。

（2）参考主题配置，替换并修改全局配置。

参考主题配置（demo/example)里的hugo.toml，将其与dev下的hugo.toml替换，并修改hugo.toml里的部分内容：

注释掉模块导入的配置（[[module.imports]]），新增 theme 字段指定本地新主题文件夹名，同时按需调整基础配置适配中文环境。

如：添加theme = “主题文件夹名称”，将baseURL替换成自己的GitHub Pages域名。

hugo.html配置更改：

（1）pagination：分页==1页能放多少篇文章。

5.public文件夹处理的注意事项

（1）public底下的都是自动生成的，改完格式以后要随时清空，使其重新生成。

（2）改任何东西都不要改public底下的。

6.content文件夹下各文件夹的存放内容

（1）post文件夹：

存放文章。post文件夹下的各个文件夹名==文章名。

中英文添加-改.md文件的语言编号：将index.==zh-cn==.md复制黏贴重命名，改名为inddex.==en==.md。

zh -> 中文

zh-cn 简体中文

zh-hk/zh-tw 繁体中文 （hongkong香港，台湾）

en/什么都不写 -> 英文（默认）

ja -> 日文

如何创建文章？

在post文件夹下，创建子文件夹，子文件夹下创建文章

，并指定创建地址+文件名：

hugo new dev下文件夹a 文件夹a下文件夹b …/文件名/index.md

如：hugo new post/test/index.md -> 创建test子文件夹，在post下创建index.md文件。

==子文件夹名=文章名，子文件夹下的index.md文件=文章==

注：更改博客文章（index.md)的内容时，要遵循.md语法。

只需在index.md里写文章内容，文章格式由markgown语法自动识别并生成。

注意：index.md文件中， TOML 格式 Front Matter（元数据）开头结尾一定要加分隔符 +++。
